## Deskripsi Aplikasi
Aplikasi **Menu Restoran** (ResMenu) adalah aplikasi berbasis Android yang dirancang untuk membantu pengelola restoran dalam mengelola daftar menu dan profil restoran mereka secara digital. Aplikasi ini dikembangkan menggunakan **Jetpack Compose** dengan arsitektur modern untuk memberikan pengalaman pengguna yang responsif dan menarik.

Aplikasi ini memungkinkan pengguna untuk melihat daftar menu, menambahkan menu baru, mengedit informasi menu yang sudah ada, serta melihat detail dari setiap hidangan. Selain itu, terdapat fitur manajemen profil restoran yang memungkinkan perubahan informasi seperti nama restoran, email, alamat, jam operasional, hingga foto banner restoran.

## Fitur Utama
- **Splash Screen:** Tampilan awal yang menarik saat aplikasi pertama kali dibuka.
- **Manajemen Menu:**
    - Menampilkan daftar menu makanan dan minuman.
    - Menambahkan menu baru dengan detail nama, harga, dan deskripsi.
    - Mengedit informasi menu yang sudah tersedia.
    - Menghapus menu dari daftar.
    - Detail menu untuk melihat informasi lengkap setiap hidangan.
- **Profil Restoran:**
    - Menampilkan informasi lengkap restoran.
    - Mengedit profil restoran termasuk Nama, Email, Alamat, Deskripsi, dan Jam Buka.
    - Fitur pilih gambar banner restoran dari galeri perangkat.
- **Penyimpanan Data:** Menggunakan **SharedPreferences** untuk menyimpan informasi profil dan pengaturan aplikasi secara lokal.
- **Dark Mode Support:** Mendukung tema gelap untuk kenyamanan visual pengguna.
- **Navigasi:** Menggunakan **Compose Navigation** untuk perpindahan antar halaman yang mulus.
